# Privacy Policy for OneWayRP-2pj

Last Updated: July 2026

## 1. Introduction

OneWayRP-2pj is a Discord bot used to manage and automate services for the OneWay Roleplay community. This Privacy Policy explains what data we collect, how we use it, and how we protect user information.

By interacting with OneWayRP-2pj, you agree to the terms outlined in this Privacy Policy.

---

## 2. Information We Collect

The bot may collect and process the following data from Discord:

- Discord User IDs
- Discord Server IDs
- Discord Role IDs
- Discord Channel IDs
- Message content (only when necessary for bot commands, moderation, ticket support, and automation)
- Member presence/status (if required for bot functionality)
- Server activity related to bot commands and automation

We only collect the minimum amount of data required for bot functionality.

---

## 3. How We Use Data

The collected data is used strictly for:

- User verification and whitelist processes
- Role synchronization and permission management
- Support ticket handling
- Moderation and server security
- Command processing
- Logging and automation
- Community management features

We do not sell, rent, or share user data with third parties.

---

## 4. Data Storage

Some bot-related data may be stored outside Discord in secure databases or server storage to ensure proper bot functionality.

Examples include:

- User verification records
- Role synchronization records
- Ticket logs
- Moderation logs
- Configuration settings

Stored data is only accessible by authorized administrators and staff.

---

## 5. Data Retention

We retain data only as long as necessary to provide bot services, maintain server security, and support moderation functions.

Data that is no longer needed may be deleted periodically.

---

## 6. AI / Machine Learning

Message content and user data collected by OneWayRP-2pj are **not used** to train artificial intelligence or machine learning models.

---

## 7. User Rights

Users may request information regarding stored bot-related data or request removal of certain stored information where applicable.

Requests can be made through the official OneWay Roleplay Discord support system.

---

## 8. Security

We take reasonable technical and administrative measures to protect collected data from unauthorized access, misuse, or disclosure.

However, no system is 100% secure.

---

## 9. Changes to This Policy

This Privacy Policy may be updated periodically to reflect changes in bot functionality, legal requirements, or operational needs.

Updated versions will be posted publicly.

---

## 10. Contact

If you have questions regarding this Privacy Policy, please contact the OneWay Roleplay administration team through the official Discord server.
